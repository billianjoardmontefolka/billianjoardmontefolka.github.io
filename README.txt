BILLIAN MONTEFOLKA — PROFESSIONAL PORTFOLIO

CONTENTS
- index.html: portfolio website
- assets/billian-portrait.png: profile portrait used by the website

HOW TO VIEW
1. Extract this ZIP archive.
2. Open index.html in a modern web browser.
3. Keep the assets folder next to index.html so the portrait loads correctly.

PUBLISHING
Upload the contents of the extracted folder (index.html and assets folder) to your preferred static website host. Do not upload only the ZIP file unless the host specifically supports ZIP deployment.

NOTES
The website uses Google Fonts when an internet connection is available and falls back to system fonts otherwise. Check your contact details before publishing publicly.
